h53 is the website for our family cabin: part guidebook, part guestbook. Family and friends sign in with Clerk, using passkeys or a social login, before they can join in.

The guide holds everything you need to know during a stay: how to get through the barrier gate, where the key safe is, and how to fire up the sauna and the hot tub. The guestbook is where visitors leave a few lines about their trip, and Convex keeps it in sync in real time. There is also a breakfast page where everyone orders their eggs, and the cook gets a summary of the orders. It has done more for cabin harmony than any set of house rules.

Mountain weather changes fast, so the header shows the current forecast from Yr (MET Norway), refreshed automatically. Handy for deciding between the ski trail and a board game.

I also used the project to try out GitHub's spec-kit, writing a spec for each feature before building it. The UI is TailwindCSS with shadcn/ui components, with a few warm touches so it feels like a cabin and not an admin panel.
